# [关于毕业三年来的经历和感悟](https://github.com/JasperYux/gitblog/issues/3)

- 不知不觉自从21年春招离开学校已经工作了近四年的时间了。

### 初入社会

- 回忆起学生时光，没有病毒式传播且扰人心头的就业压力，没有像虾米罐头般拥挤充斥着各种体味的通勤地铁，没有让人心慌睡不着觉的职场PUA，也没有争论后还是得背的黑锅，没有麻木不堪的自我洗脑，洗脑自己只是个普通人的向现实低头....
  大学是象牙塔，住在沿海的宿舍楼，价格实惠好吃的食堂，下楼直走二十米到达篮球场，关系甚好的同龄舍友，睡到自然醒的每一个早餐，这些词语有点模糊，也甚是怀念。
- 初入社会的时光是痛苦的，不堪的，不体面的，是需要克服心理脱下孔乙己的长衫的，是的，没错，我不是一个乐观的人，并且我是个在父母保护下“娇气”的人，第一份工作，原本已拿到几份Java开发实习的我，鬼迷心窍的选择了亲哥的推荐，去了一家不足20人的嵌入式设备销售公司，面试时老板美名其曰，培养年轻人成为算法图像工程师（C++），实则在一小段学习的时间后，还是被派往郊区的比亚迪工厂安装激光设备，拧螺丝，让人啼笑皆非，我真的是很天真，毫无任何准备的我，去郊区工厂呆了三天，早八晚十二，吃盒饭，住廉价酒店，没有换洗衣服，同样的衣服裤子内裤袜子穿了三天，其实这些事情不是什么大事情，我本身就是工厂长大的孩子，但是这击碎了我对生活的幻想，于是，一个幼稚的，刚毕业的大学生会选择做什么呢？是的，朝母亲诉苦，崩溃后才意识到需要自救，我需要重新投递Java开发的岗位，在努力过后，真的不得不承认运气很好，因为当时的我实在是太菜了，没有实习经验，甚至连postman都不会用，结果成功入职了一家智能家居的独角兽公司。

### 第一份工作

- 回忆起第一份工作，虽然记忆已经有些模糊，但还是很感谢公司，虽然待遇很一般，但很有人情味，校招员工入职有很多活动，认识了很多同年毕业的朋友，遇到了很好很好的导师，工作氛围也不错，虽然只在这家公司呆了一年，在刚入职时遇到同是校招入职2年的同事跳去阿里，在这一年，对技术还是有追求的，也会看技术书籍，第一份工作只工作了一年的时间，由于疫情的影响，加上国内房地产泡沫的破灭，智能家居这种作为装修环境中锦上添花的物件，大众的消费欲望下降是不难预料的事情，虽然公司融资了十亿想冲刺上市，但还是被投资人要求削减人员，裁员了百分之四十的人员，那么作为毕业一年的校招生，被淘汰在公司层面看来也是理所当然的事情。

### 第二份工作

- 在第一份工作被裁员后，刚好房子到期，和父母坦白了现状，出人意料的是父母在极力的安慰我，就搬回了父母家，同时着手于面试准备，出乎意料的是，找的非常快，可能是运气很好吧，不过也能感受到一年经验找工作的难度了，我海投了广州深圳的岗位，只有四个面试，在面试第三家公司的时候就拿到offer了，由于这个原因加上被焦虑洗脑，我报出的薪资也比较低，刚离职不到三个星期，我就入职了。
  这一份工作还挺痛苦的，小公司的管理混乱体现出来了，毫无技术氛围可言，领导工作了二十多年，在各个大厂都呆过，毫无意外的卷，晚上开会，语言打压，各种重构，重构意味着工作量巨大，996，重构也意味着不稳定，线上问题频发，各种加班，甚至通宵解决问题，客户是海外的，沟通方面也让人心累，薪资方面也毫无起色，抠门的小公司（300+人），老板对员工的鄙视毫不遮掩。
  目前我还在这家公司就职，上周一，领导被裁员了，这周，公司派出人事，全员降薪，明明公司的营收都十分正常，也许真的需要考虑离开了。

### 感悟

- 毕业后的这三年，时间很快，经历了也挺多，从学生身份到职场人身份的转变让我痛苦，两点一线毫无社交的生活让我麻木，深圳节奏的飞快，互联网病毒般肆虐的消极信息让我焦虑，一边焦虑一边自救，多少个失眠的夜晚，我自己也意识到了自己是悲观主义者，未来会怎么样？我不知道，但还是要鼓励自己，不要无痛呻吟，要持续学习，继续加油吧。
